# 🌸 Flor Morena — E-commerce

> Projeto interdisciplinar para criação da plataforma web da loja de roupas **Flor Morena**.

---

## 📌 Sobre o Projeto

A **Flor Morena** é uma loja de roupas físicas que ainda não possuía presença digital por meio de um e-commerce próprio. Este projeto foi concebido para suprir essa necessidade, desenvolvendo uma plataforma web moderna, acessível e intuitiva para que os clientes possam visualizar as coleções, peças de vestuário e informações do estabelecimento.

O projeto está sendo desenvolvido como parte de uma atividade interdisciplinar acadêmica e encontra-se em suas fases iniciais de desenvolvimento.

---

## 🚀 Estado Atual do Projeto

No momento, o projeto conta com:
- [x] Estruturação das páginas e conteúdos em **HTML5**;
- [x] Estilização e layout responsivo com **CSS3**;
- [x] Estrutura da pasta de marcas, coleções e *assets* (imagens de produtos, ícones e mídias).

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** — Estruturação do conteúdo e acessibilidade.
* **CSS3** — Design, cores, tipografia e estilização.

---

## 🔮 Próximos Passos (Roadmap)

Como o projeto está em evolução constante, as próximas etapas incluem:

- [ ] **Aprimoramento do Layout:** Integração com **Bootstrap** para acelerar a responsividade e componentes visuais.
- [ ] **Modelagem e Integração de Banco de Dados:** Criação e estruturação do banco de dados para gerenciamento de catálogo de produtos, estoque e usuários.
- [ ] **Lógica de Negócio / Interatividade:** Implementação de scripts em JavaScript para carrinho de compras e filtros de navegação.
